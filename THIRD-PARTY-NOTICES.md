The Torpor programs in `dist/` contain the Rust crates listed below, at the versions pinned in `Cargo.lock`, the C libraries bundled in two of those crates, the Rust standard library and, in the two Linux programs, musl libc. Each program contains the parts that apply to its platform. Most of these licences require the copyright and licence notices to stay with copies of the programs, so this file reproduces them.

For two parts offered under a choice of licences, this file reproduces only the option Torpor uses: zstd is used under BSD-3-Clause (not GPL-2.0-only) and the Rust standard library under Apache-2.0 (not MIT).
